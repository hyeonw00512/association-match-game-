# 마음이 통했어! — 2인 연상 단어 게임

두 명이 같은 시작 단어를 보고 연상 단어를 **서로 보지 못한 채** 제출합니다. 둘 다 제출하면 단어가 동시에 공개되며, 일치할 때까지 라운드를 이어갑니다.

## 실행 방법

1. 이 폴더에서 Node.js 18 이상이 설치되어 있는지 확인합니다.
2. 의존성을 설치합니다.

   ```bash
   npm install
   ```

3. 서버를 실행합니다.

   ```bash
   npm start
   ```

4. 두 브라우저(또는 두 기기)에서 `http://localhost:3000`을 엽니다. 한 사람이 방을 만들고, 표시된 6자리 방 코드를 다른 사람이 입력해 참가합니다.

같은 Wi-Fi의 다른 기기에서 접속하려면, 서버를 실행한 컴퓨터의 로컬 IP를 확인한 뒤 `http://로컬IP:3000`으로 접속합니다. 예: `http://192.168.0.10:3000`.

## 포함 기능

- 닉네임, 최대 2~8명 방 만들기 및 6자리 방 코드 입장
- 방장이 대기 중인 방을 취소할 수 있는 실시간 방
- 방장의 시작 단어 설정
- 단어 비공개 제출과 모든 참가자 제출 뒤 동시 공개
- 2라운드부터 직전 라운드의 모든 단어를 보고 연상하며, 내 단어/상대 단어를 구분해 표시
- 게임 시작 뒤 방 코드는 숨기고, 단어가 다르면 곧바로 다음 라운드 입력으로 자동 전환
- 새로고침해도 30초 안에는 같은 방과 진행 중인 라운드로 자동 복귀
- 공백과 대소문자를 무시한 일치 판정
- 라운드 기록, 다음 라운드, 방장의 새 게임 시작
- 10개 카테고리, 총 200개 주제의 전체/카테고리별 랜덤 뽑기

## 참고

게임 상태는 서버 메모리에만 저장됩니다. 서버를 재시작하면 열린 방과 기록은 사라집니다.

## 무료로 인터넷에 배포하기 (Render)

`render.yaml`이 포함되어 있어 GitHub 저장소만 연결하면 됩니다.

1. GitHub에서 새 저장소를 만듭니다. 이름은 예를 들어 `association-match-game`으로 하고, README 추가는 선택하지 않습니다.
2. 이 폴더의 `node_modules`를 제외한 파일을 새 저장소에 올립니다. `.gitignore`가 이를 자동으로 제외합니다.
3. [Render](https://render.com/)에 GitHub 계정으로 로그인한 뒤 **New + → Blueprint**를 선택합니다.
4. 방금 만든 GitHub 저장소를 선택하고, 표시되는 `association-match-game` 서비스를 확인한 뒤 **Apply**를 누릅니다.
5. 배포가 끝나면 Render가 제공하는 `https://...onrender.com` 주소를 두 플레이어가 열면 됩니다.

무료 서버는 15분 동안 접속이 없으면 잠들 수 있습니다. 다시 접속하면 약 1분 뒤 자동으로 켜집니다. GitHub에 변경 사항을 올릴 때마다 Render가 자동으로 새 버전을 배포합니다.
